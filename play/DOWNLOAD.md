# Download APK from GitHub Actions

Phone par install karne ke liye pehle GitHub Actions se APK download karo.

## Steps

1. Open https://github.com/companymehra899-cloud/Chess3d/actions
2. Left side me **Build Android APK** select karo
3. Agar run nahi dikhe to **Run workflow** dabao, branch `main` rakho
4. Green tick aane ka wait karo (5-10 min)
5. Us run pe click karo
6. Page ke end me **Artifacts** me ye files milengi:
   - `Chess3DArena-APK` phone pe install ke liye
   - `Chess3DArena-AAB` Play Store upload ke liye
7. APK zip download karo, unzip karo, `Chess3DArena-1.0.0.apk` phone pe copy karo
8. Android me **Install unknown apps** allow karke APK install karo

Play Store pe daalne ke liye AAB use karo, APK nahi.
